# 0.16.1 换账号扫码无应用使用权限

问题：用户用另一个账号扫描本机默认应用的授权码后，飞书提示该账号无法使用此应用。二维码由所选应用发起，账号扫码不能修改该应用；企业自建应用受企业和可用范围限制。

处理：重新绑定前明确选择继续用当前应用扫码或更换应用。显示当前应用和跨企业使用指引；二维码旁提供无法使用应用时的更换入口。扫码继续以个人身份交付。该调整帮助选择正确应用，不会绕过飞书限制或自动创建应用。

验收：103 项 Node 和 25 项 Chromium 用例。新增重新绑定选择期间不生成二维码、跨企业配置入口、扫码无使用权限时换应用、取消保留原账号回归。保留历史原生会话、报告链接和默认 CLI 配置。
