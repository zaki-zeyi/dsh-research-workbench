# PRD 修订 941：历史页面默认报告，按需打开 AI 对话

来源：[调研工作台 PRD](https://zcnnosk3k1j9.feishu.cn/wiki/Twspww4ZKiUQI8krBGlc2VCsnmr)，2026-10-27 读取 revision 941。

变更原文：“点击某个卡片可以呈现【历史调研页面】，页面默认显示历史调研报告，点击按钮【AI对话】打开历史的终端会话的页面”。

## 实现

- 卡片、最近调研和已有 `#任务ID` 链接统一默认显示完整报告；不再默认打开终端或右侧会话记录。
- 详情页提供“调研报告”“AI对话”切换入口。对话是独立内容视图，原生终端沿用同一 terminalId；旧非终端记录保留会话日志的展示能力。
- `#任务ID` 对应报告，`#任务ID/chat` 对应对话。刷新、直达链接、浏览器前进后退均保留对应视图，API/SSE 始终使用纯任务 ID。
- 新建调研仍直接进入对话页，展示真实终端的执行过程。没有报告的历史任务显示已保留草稿或等待状态，错误和重试入口继续保留。
- 报告视图不挂载 xterm、不建立终端 WebSocket、不发送输入。切换离开对话仅关闭页面连接，后端 PTY 继续保留；重新打开对话回放已有输出，用户可输入新要求。
- 点击上传飞书或继续授权时跳转原会话的对话页；平台不增加调研执行，不修改已有报告。
