# 0.17.1 工作台一直显示正在启动

现场：宿主 3090 的状态接口返回 ready，后端 3088 正常；旧浏览器页面连接失败并停留在加载状态。使用新的已授权浏览器会话可正常加载 21 条记录，桌面端数据也正常。

修复：启动请求及响应体读取设置 8 秒超时；宿主持续 starting 最多等待 20 秒；异常 HTTP、授权失效和无效状态均显示可处理错误及“重新连接工作台”。重试不创建任务、不重启 Agent、不改变飞书绑定或历史数据。离开面板后终止请求并清理定时器，迟到旧响应不能覆盖新状态。启动请求禁用缓存，并携带同源凭据。

新增 4 项 Node 回归用例，覆盖挂起的请求与 JSON 响应体、持续 starting、401/403/503/异常状态、重试恢复及迟到响应。真实 DSH 宿主浏览器验收新增挂起启动请求后超时提示、点击重试恢复工作台，再执行既有原生会话及云端交付检查。

全量 Node 113 项；浏览器交互 26 项；真实宿主和离线发布包分别验收。旧页面若宿主访问授权已经失效，需要使用当前服务生成的完整链接重新打开；重试不能绕过宿主认证。
