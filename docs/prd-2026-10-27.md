# PRD 更新 · 2026-10-27

来源：[调研工作台 PRD](https://zcnnosk3k1j9.feishu.cn/wiki/Twspww4ZKiUQI8krBGlc2VCsnmr)，读取时页面显示“最近修改：刚刚”。新增原文：

> ai会话后台是启动一个codex的命令行对话，并映射到前端，可以前端跟继续跟codex对话。（codex默认打开系统全部权限）

实现为工作台启动的 Codex 子进程默认使用：

```bash
codex --sandbox danger-full-access --ask-for-approval on-request ...
codex resume <session-id> --sandbox danger-full-access --ask-for-approval on-request ...
```

- 当前用户的文件系统及网络完整访问；保留 Agent 按需请求操作确认。
- 不改全局 Codex 配置，不授予 root、不改变 macOS 权限设置。
- 新任务和恢复历史会话的新进程共用相同参数。正在运行的进程不会热切换权限，页面刷新继续使用原进程。
- 终端元数据记录实际启动模式，WebSocket 同步到前端，避免将旧受限会话显示为完整访问。
- 新建调研页面展示默认完整访问；终端页面展示该进程的权限记录。
- 飞书保存、授权二维码及交付回执仍由终端 Agent 完成。

官方说明：[Sandbox](https://learn.chatgpt.com/docs/sandboxing)、[Agent approvals & security](https://learn.chatgpt.com/docs/agent-approvals-security)。本次同时核对了本机 `codex --help` 和 `codex resume --help`。

验证：`npm run acceptance`，36 项后端和 7 项 Chromium 验收通过，生产构建通过。新增 AC-PTY-10、AC-PTY-11，并扩展 AC-UI-06。
